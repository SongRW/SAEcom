# SAEcom Phase 1 脚本编辑器画布优先 UI 调整设计

**日期**: 2026-06-16
**分支**: develop_srw
**状态**: 设计已确认，待写实现计划

---

## 1. 背景

Phase 1 已经把脚本编辑器切到 React + Rete 路径，但当前 dialog 内存在两层横向分栏：

- 外层左侧节点列表、右侧脚本列表常驻
- 内层又把 Rete 区域拆成画板、节点快捷条、节点配置面板
- 结果是节点画板只占整体宽度的一小部分，复杂脚本很快会显得拥挤

用户确认希望参考网络拓扑类画布交互：画板是主工作区，资源列表和配置界面默认隐藏，需要时再展开。

## 2. 目标

本调整只改变脚本编辑器的布局和交互，不改变 Rete 图数据结构、脚本持久化格式、codegen、运行/停止 IPC。

目标：

- 默认最大化画布面积
- 隐藏脚本列表和组件选择，按需从窄栏或工具栏打开
- 单击节点只选中，双击节点打开组件对象配置
- 配置界面不遮断画布上下文，采用右侧临时抽屉
- 支持亮色和暗色两套主题
- 视觉语言接近 shadcn/ui：语义色、克制边框、微弧边按钮，避免大圆角胶囊按钮

## 3. 已确认方案

采用 **B 方案：左侧窄图标栏 + 画布主区 + 右侧临时抽屉**。

### 3.1 主布局

```
ScriptEditorDialog
├─ Toolbar
│  ├─ 当前脚本名称
│  ├─ 新建 / 保存 / 删除
│  ├─ 运行 / 停止
│  └─ 缩放 / 适配 / 关闭
├─ Body
│  ├─ 左侧窄图标栏
│  │  ├─ 组件
│  │  ├─ 脚本
│  │  ├─ 输出
│  │  └─ 预留扩展入口（本次不实现新功能）
│  └─ Rete 画布
│     ├─ 顶部浮动快捷条：节点分类、添加到画布
│     ├─ 节点与连线
│     ├─ 右侧抽屉：节点配置 / 脚本列表 / 组件列表
│     └─ 底部输出面板：可收起
```

画布区域不再被节点快捷条和配置面板永久切分。右侧抽屉只在用户打开组件、脚本或节点配置时覆盖在画布上方。

### 3.2 左侧窄图标栏

左侧栏宽度约 48px，常驻，但只放图标按钮：

- 组件：打开组件选择抽屉
- 脚本：打开脚本列表抽屉
- 输出：展开或收起底部输出面板
- 保留一个扩展入口，不在本次实现中增加新功能

图标按钮使用 34-36px 方形按钮，`border-radius` 约 6px。选中态使用 `primary` token 的轻量边框或背景，不使用高饱和大面积渐变。

### 3.3 组件选择

组件选择不再是常驻左栏。

入口：

- 点击左侧栏“组件”图标
- 或点击画布顶部浮动快捷条的“添加到画布”

展示方式：

- 右侧抽屉展示节点分类和节点列表
- 顶部浮动快捷条展示常用分类切换，便于快速添加
- 点击节点在当前视口中心或默认偏移位置添加
- 拖拽到画布仍保留

### 3.4 脚本列表

脚本列表不再是常驻右栏。

入口：

- 点击左侧栏“脚本”图标
- 或工具栏当前脚本名称区域的下拉/按钮

展示方式：

- 右侧抽屉展示已保存脚本
- 点击脚本后加载脚本并关闭或保留抽屉；默认加载后关闭，让画布回到主视图
- 加载错误显示在抽屉内，不影响画布

### 3.5 节点配置

节点交互：

- 单击节点：选中节点，仅改变节点高亮状态
- 双击节点：打开右侧节点配置抽屉
- Delete / Backspace：删除选中节点，沿用现有快捷删除能力

配置抽屉：

- 标题显示节点 label 和 key
- 参数区沿用现有 `NodeControls`
- 输入连线区沿用现有 `NodeConnections`
- 删除按钮保留在抽屉底部或标题右侧
- 保存配置按钮只关闭抽屉；实际数据仍然即时同步到 graph state，避免引入额外草稿状态

选择右侧抽屉而不是中心弹窗，是为了用户配置节点时仍能看到节点所在画布上下文和连接关系。

### 3.6 输出面板

底部输出面板改成默认收起或较低高度显示。

- 运行脚本时自动展开
- 左侧栏“输出”按钮可切换展开/收起
- 保留清空输出按钮
- 不改变运行日志的数据来源和 store

## 4. 视觉规范

### 4.1 shadcn 风格约束

- 使用现有 `src/components/ui/button.tsx` 能覆盖的按钮优先用 `Button`
- 自定义结构使用现有 CSS token：`--background`、`--foreground`、`--card`、`--muted`、`--border`、`--primary`
- 不使用大圆角胶囊按钮；普通按钮和抽屉圆角控制在 4-6px
- 图标按钮使用明确图标，不用长文字按钮代替工具动作
- 不引入大面积渐变、装饰光斑或强装饰背景

### 4.2 亮色与暗色模式

脚本编辑器必须适配现有主题变量：

- 亮色：浅色画布网格、白色节点、浅边框
- 暗色：深色画布网格、深色节点、低对比边框
- 不在组件里硬编码 `dark:` 双份颜色，优先使用 CSS 变量
- `.dark` class 切换时，dialog、画布、抽屉、节点、按钮都应自然切换

### 4.3 画布视觉

- 画布背景使用轻量点阵或网格，不能压过节点内容
- 节点卡片为 6px 左右圆角
- 选中节点用 primary 边框和轻量 ring
- 连线保持可读，但不使用过粗或高饱和装饰线
- 浮动快捷条放在画布顶部，背景半透明或 card 色，避免遮挡大量画布

## 5. 组件与状态设计

### 5.1 新增 UI 状态

在 `ScriptEditorDialog` 或局部 reducer 中维护：

```ts
type ScriptEditorDrawer = 'nodes' | 'scripts' | 'config' | null

interface ScriptEditorUiState {
  drawer: ScriptEditorDrawer
  outputExpanded: boolean
}
```

规则：

- 点击左侧组件图标：`drawer = drawer === 'nodes' ? null : 'nodes'`
- 点击左侧脚本图标：`drawer = drawer === 'scripts' ? null : 'scripts'`
- 双击节点：设置 `selectedNodeId`，并 `drawer = 'config'`
- 删除选中节点：清空 `selectedNodeId`，关闭配置抽屉
- 运行脚本：`outputExpanded = true`

### 5.2 组件拆分

建议拆分：

- `ScriptEditorRail.tsx`：左侧窄图标栏
- `ScriptEditorDrawer.tsx`：右侧抽屉容器
- `NodeConfigPanel.tsx`：从当前 `GraphCanvas` 抽出节点配置内容
- `CanvasQuickAdd.tsx`：画布顶部快捷分类与添加入口

`GraphCanvas` 只负责 Rete 初始化、节点/连线同步、拖拽放置和画布事件，不再渲染常驻节点快捷条和常驻 inspector。

### 5.3 数据流

保留现有数据流：

- `graph` 仍由 `ScriptEditorDialog` 持有
- `GraphCanvas` 通过 `onGraphChange` 更新 graph
- 节点参数编辑仍调用 `updateGraphNodeData`
- 输入连线仍调用 `connectGraphNodes` / `removeGraphConnection`
- 保存和运行仍从 `exportGraphState(graph)` 生成代码

本次不改变 `GraphEditorState`、Rete export 格式、`buildScriptFile` 或 `generateCodeFromRete`。

## 6. 响应式策略

桌面窗口：

- Dialog 尽量使用 `calc(100vw - 32px)` 和 `calc(100vh - 32px)`
- 左侧栏 48px 常驻
- 右侧抽屉宽度约 320px，覆盖画布右侧

窄屏：

- 左侧栏仍保留
- 右侧抽屉宽度使用 `min(320px, calc(100vw - 72px))`
- 输出面板展开高度降低
- 顶部工具栏允许换行，但按钮尺寸保持稳定

## 7. 测试与验证

自动化测试：

- 补充 view model 或 UI state 测试，覆盖抽屉切换、双击打开配置、运行展开输出等纯状态逻辑
- 保留现有 graph state 测试，确保节点配置和连接逻辑不变

手动验证：

- 打开 Electron 开发版，点击“编辑脚本”
- 默认画布面积明显大于当前版本
- 点击左侧组件图标，组件抽屉出现；再次点击关闭
- 点击左侧脚本图标，脚本抽屉出现；选择脚本后加载正常
- 单击节点只选中，不打开配置
- 双击节点打开右侧配置抽屉
- 修改参数后保存脚本，重新加载数据仍正确
- 运行脚本后输出面板自动展开
- 在亮色和暗色主题下检查按钮、节点、抽屉、画布网格可读

## 8. 非目标

- 不重写 Rete 节点定义
- 不改变 codegen 行为
- 不改变脚本文件格式
- 不新增 Drawflow 到 Rete 的旧脚本转换
- 不新增复杂快捷键系统
- 不引入新的全局主题系统

## 9. 验收标准

1. 默认状态下，画布占据 dialog 主体绝大部分空间
2. 脚本列表、组件选择、节点配置均不再常驻挤占画布
3. 单击节点只选中，双击节点打开右侧配置抽屉
4. 亮色和暗色模式下 UI 均可读，并符合 shadcn 的克制视觉语言
5. 保存、加载、运行、停止、节点连接和参数编辑行为不回退
6. `npm test`、`npm run typecheck`、`npm run build` 通过
